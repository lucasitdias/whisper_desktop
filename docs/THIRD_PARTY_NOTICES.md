# Avisos de terceiros

O Whisper Transcriber Desktop distribui e utiliza componentes de terceiros.

## OpenAI Whisper

- Projeto: <https://github.com/openai/whisper>
- Licença: MIT
- Os pesos do modelo `turbo` são baixados na primeira utilização e não são incorporados ao
  repositório nem ao executável.

## FFmpeg

- Projeto: <https://ffmpeg.org/>
- Build estático: <https://github.com/BtbN/FFmpeg-Builds>
- Versão fixada: FFmpeg 8.1.2, variante LGPL, release `autobuild-2026-07-31-14-10`.
- O executável FFmpeg permanece um programa separado, invocado por subprocesso.

Os textos e fontes correspondentes das licenças permanecem disponíveis nos projetos acima. A
distribuição de uma release deve conservar este arquivo junto aos artefatos publicados.
